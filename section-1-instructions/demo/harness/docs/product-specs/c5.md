# Control task: Admins cannot change their own role

A small rule on an existing write endpoint.

## Behaviour

`PATCH /users/{user_id}`, when `user_id` is the caller's own id and the body sets `role` to a value
different from the caller's current role, gives 422 with the error code `cannot_change_own_role`
(raise `Invalid` with that code). The request changes nothing: not the role, not the name, and it adds
no audit row.

- Changing your own `name`, or sending your own current role, still works (200).
- Admins still change other users' roles and names, as before.
- Everything else is unchanged: only admins may call the endpoint (others get 403 `forbidden`), and a
  user of another org gives 404 `not_found`.

## Where the change goes

`app/services/users.py` and tests in `tests/visible/`.
