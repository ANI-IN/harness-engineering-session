# Module 1: Harness Engineering for Coding Agents - Slides

This folder holds the class deck, one PowerPoint file:
[Harness Engineering for Coding Agents.pptx](Harness%20Engineering%20for%20Coding%20Agents.pptx).
It is the only deck for the 240-minute class, with 75 slides.

## How to view it

- Present: open the file in PowerPoint and use the presenter view.
- The speaker notes are in the deck. There is no separate notes file and no PDF.

The course diagrams, with their Excalidraw sources, are under `docs/diagrams/` and
`section-N-*/diagrams/`.
