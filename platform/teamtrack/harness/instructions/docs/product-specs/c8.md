# Control task: Show the assignee on the board's issue page

A small change to the web board.

## Behaviour

The issue detail page (`/board/issues/{issue_id}`) shows who the issue is assigned to, as an
"Assignee" entry in its details list, for every signed-in role:

- assigned: `<dd class="assignee" data-user-id="<user id>"><user name></dd>`, for example
  `<dd class="assignee" data-user-id="2">Acme Member</dd>`;
- not assigned: `<dd class="assignee">Unassigned</dd>`.

The page shows the current assignee, so it follows reassignments. Everything else on the page, and the
rules for who may see it (another org's issue gives 404), are unchanged. The board never imports
`app.db` (House rule 6: Layering): get the user through a service.

## Where the change goes

`app/web/routes.py`, `app/web/templates/issue.html`, and tests in `tests/visible/`.
