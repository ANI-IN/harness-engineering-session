# Feature 6: Watchers

Status: planned. Final project (two sessions).

## Goal

Users follow the issues they care about and see them in one list.

## API

| Endpoint | Who | Result |
|---|---|---|
| `PUT /issues/{issue_id}/watchers/me` | writers | 204; the caller watches the issue |
| `DELETE /issues/{issue_id}/watchers/me` | writers | 204; the caller no longer watches it |
| `GET /issues/{issue_id}/watchers` | any role | list of `{"user_id", "created_at"}` |
| `GET /me/watching` | any role | list of `IssueOut`, the issues the caller watches |
| `PUT /issues/{issue_id}/watchers/{user_id}` | admins | 204; that user watches the issue |
| `DELETE /issues/{issue_id}/watchers/{user_id}` | admins | 204; that user no longer watches it |

- Watching an issue you already watch returns 204, changes nothing, and adds no audit row. Removing a
  watcher who does not watch the issue also returns 204 and adds no audit row.
- Viewers get 403 `forbidden` on every write; members get 403 on the two admin endpoints.
- Another org's issue gives 404 `not_found`. The `{user_id}` endpoints accept only users of the
  caller's org; any other user id gives 404. A deleted issue, or an issue in an archived project, gives
  404 on every endpoint above that names it.
- `GET /me/watching` never lists deleted issues or issues of archived projects.
- Lists use the envelope `{"items": [...], "next_cursor": ...}` with `cursor` and `limit` (1 to 100,
  default 20). `GET /issues/{issue_id}/watchers` is ordered by when the watcher was added (ascending
  watcher id); `GET /me/watching` is ordered by ascending issue id.
- Audit: adding a watcher adds one row `watcher.add`, removing one adds one row `watcher.remove`, both
  with entity `issue` and the issue's id. Refused writes and no-op writes add none.

## Data

- New table `watchers` (`id`, `org_id`, `issue_id`, `user_id`, `created_at`, one row per issue and
  user) in exactly one new Alembic migration on the current head.
- Seed, with stable ids: each org's member watches the org's first two issues. Acme: watcher 1 (issue
  1) and 2 (issue 2), user 2. Globex: watcher 3 (issue 21) and 4 (issue 22), user 5.

## Out of scope

Notifications, watching projects.
